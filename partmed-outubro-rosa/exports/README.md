# Partmed • Outubro Rosa — resolução completa

`Partmed-Outubro-Rosa-FINAL.mp4` é a exportação em alta qualidade da edição v4, com fundo branco/rosa pastel, títulos azul/rosa e legendas de fundo rosa.

- 1080 × 1920, vertical 9:16.
- 30 FPS, 2821 frames, aproximadamente 94 segundos.
- MP4 H.264, CRF 16.
- Vídeos originais, sem usar os proxies de revisão.
- Locução integral tratada, com áudio AAC.
- Serviços, valores e parcelamentos preservados.

Para baixar no site do GitHub, abra o arquivo MP4 e use **Download raw file**. No Codespaces, abra a pasta `exports` no Explorer, clique com o botão direito no MP4 e escolha **Download**.

Para reproduzir a exportação em um Codespaces configurado, execute `npm run render:final` na pasta do projeto. O novo resultado fica em `out/Partmed-Outubro-Rosa-FINAL.mp4`.
